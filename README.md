# Smooth

DSH 界面美化插件，依据 `样例图/index.html`、`settings.html` 及预期截图调整侧栏、顶部标签、欢迎区、双层输入卡片和整页设置；插件页沿用原生页面，仅调整页面背景。图标使用宿主原生组件，导航和主题切换调用宿主接口。关闭皮肤后恢复原生样式和外观选项；侧栏若已被手动拖动，则保留手动宽度。

## 外观

- 图标栏 `#191b1d`、侧栏 `#202123`、主工作区 `#292c2e`、顶部标签栏与表单 `#303335`、输入卡片 `#323537`；图标栏通过背景色区分层次，主面板向会话列表投射两层外阴影，沿圆角轮廓形成抬高的层次，输入卡片的信息栏略亮于编辑区
- 深色模式正文 `#f1f2f4`，次要文字 `#c3c5ca`，辅助文字 `#b4b7bf`（三档按 OKLCh 亮度同比提亮，层级间距不变）
- 原生导航按钮与头像组成固定尺寸的紧凑左侧图标栏（栏宽约 49px、按钮 35px、图标 22px，不随窗口变化），按钮沿栏中线对齐；项目树、新会话和品牌显示在右侧
- Home 使用线条房子图标，点击仅关闭设置或其他面板，返回当前对话所在的主页面；保留当前对话，已经在主页面时不执行操作，新建仍使用“新会话”按钮
- 侧栏默认占窗口宽度的 28.5%（320–560px）；顶部仅显示已操作的对话/页面，以及一个可替换的临时预览标签，按加入顺序排列，溢出时才出现滚动箭头
- 鼠标在顶部标签栏上滚动时，上滚向左、下滚向右，以平滑缓动累积连续滚轮位移；保留触控板横向滚动，支持对话页与设置页，减少动态效果模式下直接滚动
- 主面板、原生图标底板和输入框圆角按样例比例缩放，但不再随窗口放大：样例形状按 1950px 画布定（`--smooth-u: min(1px, 100vw/1950)`），左栏 chrome 直接钉死（`--smooth-l: .91px`，参考文件对侧栏栏位用的就是这个值），标题栏高度停在 64px
- 插件页保留原生布局、图标、列表和开关；整页设置不再沿用样例图的大画布比例，改用 Harness 自身的界面尺度（导航 32px 行高、13px 字，表单 52px 行高、14px 标题、13px 说明、30px 选择器、36×20 开关），外观选项仍为三列卡片。左侧导航按「账户 / 应用 / 扩展 / 外观」分为四组：宿主把 `settings.section` 渲染成一个扁平列表，导航项身上没有 id 或分组属性，因此分组标题是按位置锚定的，增删设置项会连带移动分组边界
- 滚动条默认细线，滚动时在 160ms 内变粗，停止 650ms 后用 280ms 渐细；保持原生拖动和固定轨道宽度，减少动态效果模式下直接切换粗细。宿主没有全局滚动条规则，因此自定义样式只作用于应用自身的表层（会话滚动、侧栏、设置、菜单）：正文流内部的嵌套滚动容器保持平台叠加式滚动条，不为宽表格、代码块预留 8px 槽位
- 强调色：`#8fb7ff`（品牌）与 `#ffcd96`（暖色点缀）
- 光感集中在输入卡片、选中标签与导航项：左上方向的轻微渐变配合顶部内高光，输入框聚焦时增加柔和的强调色反光；按钮悬停和按下以 160ms 平滑明暗反馈，减少动态效果模式下直接切换

浅色模式同样成套提供，`设置 → Smooth → 日夜模式` 可切换「跟随宿主 / 固定深色 / 固定浅色」。
浅色模式使用白色输入卡片、较轻的外投影和独立的蓝灰色选中底色；正文、次要及辅助文字在主要内容和导航背景上的对比度均不低于 4.5:1。

## 覆盖范围

应用外壳与滚动条、图标栏与会话树、会话胶囊标签、整页设置与表单控件、插件管理页、输入框卡片、欢迎页、对话气泡、弹层与菜单。没有复制参考 HTML 的 SVG、图标字体或示例数据。首页房子、账号用量与帮助图标使用简短的本地 SVG，其余复用宿主图标。会话名称、工作区和插件列表来自宿主，会话树沿用当前已安装的 Codex UI 插件。

账号菜单在原生 `settings.launcher` 上增加头像资料、“剩余用量”和帮助入口，并按参考图排列，字号跟随内容区。点击“剩余用量”后，余额面板在该项下方展开，右侧箭头旋转向下，再次点击收起；充值余额四舍五入显示两位小数，赠金钱包为空或为零时隐藏，有赠金时保留其小数精度，不合并不同币种。金额按十进制字符串处理，不改变接口原始数据。打开菜单和展开时刷新，支持手动重试；读取失败不冒充零余额。账号资料和登录状态来自原生 account store，不写死昵称或 Plus 套餐。设置、反馈、登录、退出确认和账号通知仍由原生组件处理；关闭皮肤后撤销覆盖。

首页通过宿主 `remote.workspaceFiles.read()` 读取当前会话工作区的 `.git/HEAD`，支持子目录、worktree 和 detached HEAD；切换工作区立即清除旧分支，聚焦窗口及每 30 秒刷新。读取失败或无 Git 仓库时不显示分支。宿主未公开完整的 Git status 接口，因此不展示待暂存文件数量。语音输入按钮沿用语音插件的原生插槽，仅在宿主提供该功能时出现。

输入框采用单层外边框，顶部信息栏高 34px，欢迎页默认总高度约 150px；文本区随内容增高，最高 300px（小窗口不超过 40vh），同时受页面剩余高度限制，超出后内部滚动。模式与模型入口统一为 13px、32px 高，发送按钮空内容时灰显、可用时为主题蓝。普通占位提示缩短为“描述任务，/ 调用指令，@ 引用文件或对话”；工作区选择、不可用、计划和运行状态提示仍沿用原生内容。编辑器、附件、发送与停止、模型选择继续由原生组件处理。

点击账号菜单中的“帮助”，下方操作区以 220ms 淡入滑动过渡切换为帮助链接，并可点击“返回”恢复。四个入口分别为 Harness GitHub、开发者文档、社区插件和 cordis 论文，点击后通过宿主外链处理器在系统浏览器打开。切换期间保留原生设置、反馈和退出操作，非当前页不参与键盘导航。

## 工作机制

- **Host 半**（`lib/index.js`）：**不触达任何服务**。Cordis 对未写进 `inject` 的服务名会直接抛 `cannot get property "..." without inject`，所以这一半刻意只导出对象形态插件 `{ name, inject: [], apply }`，`apply` 为空。
- **Client 半**（`lib/client.js`）：注册 `settings.section` 页面、注入作用域样式表（自带 `data-plugin` 标记，避免被其他插件的热替换清理）、按状态调用 `theme.overrideTokens()`，并用 `body[data-smooth-skin]` 作为样式门控。状态存在浏览器 `localStorage`（键 `dsh-smooth-skin:state`），不经过任何 Host 通道。
- Client 产物显式导出 `name` / `inject` / `apply`；服务 `theme` / `slots` / `locale` / `layout` / `uiWorkspace` / `remote` / `remote.workspaceFiles` 均声明在 `inject` 中，manifest 同时列出相应提供模块和设置、会话模块。
- 首页权限选择通过 React portal 放入输入框顶部，模式选择放入底部；完整保留原生组件的 locale、store、inject 和确认交互。关闭皮肤时撤销插槽覆盖和 portal，恢复原生位置；不手动搬移宿主 React 管理的 DOM。
- 顶部标签通过 `layout.selectPanel()`、`uiWorkspace.startSession()` / `openSession()` 和原生设置 store 导航。打开对话或页面先显示临时标签；在内容区输入、修改表单或点击操作控件后固定，单纯浏览不会累积标签，也不会自动加入其他历史会话。双击标签也可固定。点击关闭按钮或在标签上按 Delete 仅关闭标签，保留对话数据；关闭当前标签后切换到相邻标签，全部关闭时回到首页，且首页由页面本身承担，不占标签位也不作为固定目标。标签状态属于本次客户端生命周期。通过 slots 发布的共享 store 读取侧栏宽度和设置状态；在原生设置插槽内渲染标签，保留设置窗口的焦点管理。三块外观选项调用原生 `theme.setTheme()`，关闭时撤销插槽覆盖。
- 配色通过 `theme.overrideTokens()` 提供 light / dark 两套值；样式以 `body[data-smooth-skin]` 为开关。选择器优先使用宿主的 `data-plugin-panel`、`data-plugin-package`、`data-composer-card` 等真实属性。没有公开属性的部位只匹配已核对的 CSS 模块语义后缀，不绑定构建哈希；宿主大版本升级后需重新检查这些部位。

## 开发

```bash
node build.mjs                # 生成 lib/index.js 与 lib/client.js
node build.mjs --watch        # 监听 src/ 增量重建
node tools/activate-host.mjs  # 激活试验台
node --test tests/*.test.mjs
```

`tools/activate-host.mjs` 把 Cordis / 插件加载器里 `unwrapExports` → `resolve` → 读 `name`/`inject`/`Config` 的判定逐行抄出来，导入**构建产物**核对插件契约，并断言 Host 半没有多余的 `ctx` 访问——这两类问题都曾让 DSH 启动即失败或条目无法激活。

`src/shared.js` 被打包进两个产物，是配色与状态规范化的唯一来源。

`tests/client.test.mjs` 直接执行浏览器构建产物，检查模块导出、依赖访问、设置页注册、启用/关闭和卸载清理。源码与构建产物必须完全一致，修改 `src/` 后需重新构建。

若仍出现旧版 `lib/index.js` 访问 `host` 的报错，先构建，再从托盘完全退出 DeepSeek Harness 并重新打开；只刷新页面不会清除 Host 进程已导入的模块。

## 结构

```
package.json      manifest：dsh.bundle.patch + dsh.client
cordis.patch.yml  bundle 补丁，插入 smooth-skin 行
样例图/           原始 HTML 设计参考，不参与插件运行
locale/{zh,en}.json  插件管理页显示的标题与描述
src/shared.js     调色板、主题令牌映射、状态规范化、locale 词条
src/skin.js       作用域样式表
src/composer.js   真实 Git 分支读取、输入框信息栏与原生控件 portal
src/account.js    账号资料、向下展开的真实余额与原生账号菜单扩展
src/layout.js     原生导航标签、共享布局连接与三块外观选项
src/scrollbar.js  各滚动区域的粗细动画、空闲恢复与卸载清理
src/client.js     Client 半：设置页 + 令牌覆盖 + 样式注入 + localStorage 状态
src/host.js       Host 半：无依赖的插件壳
build.mjs         构建脚本
tools/            激活试验台（复刻 cordis 的插件判定）
tests/            契约与样式作用域测试
```
